# Prostir - Modern ISP Website

Современный веб-сайт для интернет-провайдера "Простір" построенный на Vite + React + TypeScript.

## Особенности

- 🚀 Быстрая загрузка благодаря Vite
- ⚛️ React 18 с TypeScript для типобезопасности
- 🎨 Современный дизайн в стиле shtorm.net
- 📱 Адаптивная верстка для всех устройств
- 🌟 Анимации и интерактивные элементы
- 🏢 Вся информация с оригинального сайта prostir.if.ua

## Структура проекта

```
prostir-modern/
├── src/
│   ├── components/
│   │   ├── Header.tsx/css     # Навигация и логотип
│   │   ├── Hero.tsx/css       # Главный баннер
│   │   ├── Services.tsx/css   # Услуги провайдера
│   │   ├── Offers.tsx/css     # Акции и предложения
│   │   ├── About.tsx/css      # О компании
│   │   └── Footer.tsx/css     # Контакты и ссылки
│   ├── App.tsx               # Основное приложение
│   ├── main.tsx             # Точка входа
│   └── index.css            # Глобальные стили
├── index.html               # HTML шаблон
├── package.json            # Зависимости
└── vite.config.ts         # Конфигурация Vite
```

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка продукта
npm run build

# Предварительный просмотр
npm run preview
```

## Содержание

Сайт содержит все ключевые секции оригинального сайта:

- **Навигация** - современное меню с липким заголовком
- **Главный баннер** - привлекательная презентация услуг
- **Услуги** - высокоскоростной интернет, телевидение, поддержка
- **Акции** - "5+1", "10+2", временный платеж, денный тариф  
- **О компании** - информация о ФОП Юрійчук Ольга Ярославівна
- **Контакты** - полная контактная информация и способы оплаты

## Технологии

- **Vite** - быстрый сборщик
- **React 18** - библиотека UI
- **TypeScript** - типизированный JavaScript
- **CSS3** - современные стили и анимации
- **ESLint** - линтер кода

Сайт полностью готов к использованию и может быть развернут на любом хостинге!
